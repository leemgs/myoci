About Oracle Cloud Infrastructure

OCI Free Tier는 가입 후 일정 기간 사용하는 무료 크레딧과 계정의 홈 리전에서 계속 사용할 수 있는 Always Free 자원으로 구성됩니다. 개인 학습, 개발 서버, 소규모 웹 서비스 및 클라우드 실습 환경을 만들 때 유용합니다.

무료 한도와 제공 지역은 변경될 수 있으며 용량 확보가 보장되지는 않습니다. 실제 생성 전 OCI Console의 Always Free-eligible 표시와 현재 서비스 한도를 확인하세요.

Public IP와 SSH 접속

  • 인스턴스 생성 시 public subnet과 공용 IPv4 할당 여부를 선택합니다.
  • SSH 공개 키를 인스턴스에 등록하고 개인 키는 로컬에서 안전하게 보관합니다.
  • Ubuntu 기본 사용자는 보통 ubuntu, Oracle Linux는 opc입니다.
  • Security List 또는 NSG에서 필요한 출발지에만 TCP 22를 허용합니다.
  • 공용 IP 없이 OCI Bastion 또는 private network를 이용하면 노출을 줄일 수 있습니다.

접속 예시

ssh -i ~/.ssh/oci_key ubuntu@PUBLIC_IP

그 밖의 Always Free 서비스

  • Autonomous AI Database 최대 2개(각 1 OCPU, 20GB)
  • Flexible Load Balancer 1개와 Network Load Balancer 1개
  • OCI Monitoring, Notifications, Logging 및 Email Delivery 무료 한도
  • Resource Manager(Terraform), Vault, Bastion 등 운영·보안 서비스
  • 가입 시 제공되는 무료 크레딧은 Always Free 외 적격 서비스 실습에 사용

서비스마다 홈 리전 조건, 월별 요청량, 저장 용량 등의 별도 제한이 적용됩니다.

OCI의 장점과 고려할 점

장점

  • 무료 Arm Flex 자원으로 CPU와 메모리를 용도에 맞게 조합 가능
  • 상대적으로 큰 무료 Block Volume과 아웃바운드 데이터 한도
  • VCN, IAM, Load Balancer, Database 등 엔터프라이즈 기능 학습 가능
  • Console, CLI, SDK 및 Terraform을 통한 자동화 지원

고려할 점

  • 인기 리전의 A1 인스턴스는 Out of host capacity가 발생할 수 있음
  • Always Free 자원은 주로 홈 리전에서만 무료이며 서비스별 제한이 다름
  • 유휴 Compute는 Oracle 정책에 따라 회수 대상이 될 수 있음
  • Arm에서 사용할 OS 이미지와 소프트웨어의 아키텍처 호환성 확인 필요
  • 공용 IP, 방화벽, SSH 키 및 IAM 정책은 사용자가 안전하게 관리해야 함
